## My approach

<div align="center">

`RESEARCH` **→** `FORMALIZE` **→** `MODULARIZE` **→** `TEST` **→** `REFINE`

</div>

I care about the details behind the result:

- **Traceability:** where a rule came from and what evidence supports it.
- **Separation of concerns:** detection, validation, scoring, signals, and visualization are distinct responsibilities.
- **Reproducibility:** a successful compile is not a chart test, and a chart test is not a backtest.
- **Performance:** process real changes instead of repeatedly recalculating everything.
- **Design discipline:** every visual element should communicate a specific piece of information.
